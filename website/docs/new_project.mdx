# Register a new project

The first step into Tansu is to register your project with **+ Add Project**. The on-chain name must be 4 to 30 characters, letters and digits only, and unique. A longer, friendlier display name can be set in the project information file.

:::warning[Registration deposit]

Only register projects you are a maintainer of and are allowed to register. Registration takes a **5 XLM deposit**, which is not returned: it is the price of a unique name. Impersonation can be reported to the Tansu team.

:::

When registering a project, a `Tansu information file` is created for you in the background. This `tansu.toml` which is hosted on IPFS and holds metadata for your project. The dApp is using the data to make a nice project card.

You can also set the project's governance settings at registration -- minimum voting period, execution delay and attestation finality threshold -- or keep the defaults and change them later. See [Project governance settings](developers/governance.mdx#project-governance-settings).
